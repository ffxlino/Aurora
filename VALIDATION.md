# Проверка выпуска Aurora 0.2.0

Дата: 11 октября 2026. Windows x64.

## Выполнено для 0.2.0

- 19 автоматических проверок: безопасность путей и архивов, авторизация и конфликты общего сервера, зависимости ресурсов, фильтрация совместимых версий, частичная недоступность каталогов, отказ автора от сторонней загрузки, сохранность существующих файлов при ошибках и обновлении, импорт смешанного CurseForge-модпака, ручные категории и отключение модов.
- Настоящий поиск Modrinth во всех четырёх категориях. Установка Sodium 0.8.13, Lithium 0.15.4, Iris 1.8.8 и его обязательной зависимости для Minecraft 1.21.1 / Fabric; Complementary Reimagined r5.9.3 и Fresh Animations 1.10.4. Проверены соответствующие папки, источники и метаданные карточек.
- Интерфейс Electron: пять разделов без горизонтального переполнения; карточки установленных модов; выключение и включение; смена категории и возврат к автоматической; принятие и отмена встроенного подтверждения; настоящее событие закрытия при работающем сервере и отмена закрытия; подключение к HTTPS-серверу с правами администратора; изоляция Node.js от интерфейса.
- npm audit --omit=dev: 0 известных уязвимостей на момент проверки.

Результаты проверок находятся в artifacts/smoke.json и artifacts/catalog-v2-result.json. Тестовые данные и инструменты не включаются в EXE; режим --smoke использует отдельный профиль artifacts/smoke-data.

## Ограничения проверки

- CurseForge проверен на контролируемых ответах API, включая импорт модпака, зависимости, типы файлов и недоступные загрузки. Живой поиск и загрузка CurseForge не проверены: пользовательский API key отсутствует.
- Реальный вход Microsoft и запуск лицензированной игры не проверены без разрешённого Client ID и аккаунта владельца.
- Загрузка и корректное размещение файлов не подтверждают совместимость всех модов при запуске игры. Категория среды работы не является гарантией совместимости.
- Подключение друзей через интернет зависит от сети владельца; локальные HTTPS и контроль прав проверены.

В предыдущем выпуске проверялись загрузка Minecraft 1.21.1 / Java 21, Fabric 0.19.5, Forge 52.1.0, NeoForge 21.1.259 и импорт Simply Optimized Reloaded. Эти большие загрузки не повторялись в 0.2.0.
