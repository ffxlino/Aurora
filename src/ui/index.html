Только файлы сборки

Общий доступ охватывает mods, config, resourcepacks, shaderpacks, defaultconfigs и kubejs. Миры и аккаунты остаются на твоём компьютере. Синхронизация ручная; журнал обновляется каждые 15 секунд.

Для друзей через интернет компьютеру владельца нужен доступный адрес и открытый порт либо общая VPN-сеть. Встроенный сервер работает, пока Aurora открыта. Это сервер файлов сборки, а не игровой сервер Minecraft.

Microsoft и Minecraft

Войди в аккаунт Microsoft с Minecraft Java Edition. Авторизация выполняется на официальной странице Microsoft.

Производительность

Java устанавливается автоматически под выбранную версию игры. Лаунчер рассчитан на Minecraft Java 1.18 и новее, Windows x64.

CurseForge

Поиск и установка ресурсов CurseForge, а также импорт ZIP-сборок требуют собственного API key. Некоторые авторы запрещают скачивание через сторонние приложения.
