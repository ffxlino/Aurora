Только файлы сборки

Общий доступ охватывает mods, config, resourcepacks, shaderpacks, defaultconfigs и kubejs. Миры и аккаунты остаются на твоём компьютере. Синхронизация ручная; журнал обновляется каждые 15 секунд.

Для друзей через интернет компьютеру владельца нужен доступный адрес и открытый порт либо общая VPN-сеть. Встроенный сервер работает, пока Aurora открыта. Это сервер файлов сборки, а не игровой сервер Minecraft.

Аккаунт и запуск

Войди в Microsoft один раз. Aurora сохранит вход в защищённом хранилище и запустит Minecraft после проверки обновлений сборки.

Для запуска через Minecraft Launcher выбери профиль подготовленной сборки и нажми «Играть» в нём.

Обновления Aurora

Проверка при запуске и каждые 30 минут.

Производительность

Java устанавливается автоматически под выбранную версию игры. Поддерживаются Minecraft Java 1.18 и новее, Windows и Linux x64.

Оформление

Твой компьютер

Открой вкладку, чтобы обновить сведения.

Параллельные задачи

Для медленного диска выбирай 1–2 задачи. Больше задач требует больше памяти и не всегда повышает скорость. Изменение применяется после сохранения.

Шаблон настроек Minecraft

Сохраняются только стандартные клавиши, графика и звук Minecraft. Параметры модов не переносятся. Шаблон накладывается только на существующие параметры файла options.txt, созданного самой игрой. Для новой сборки — после её первого запуска.

Подключение Bisect / другого сервера
Точная проверка читает содержимое mods/config с сервера и может скачать несколько гигабайт. Клиентские моды исключаются. Подключение привязано к этой сборке. CPU, RAM и TPS файловый протокол не передаёт. Aurora не меняет файлы работающего сервера.

Мониторинг Bisect
Ключ хранится зашифрованным на этом компьютере. Aurora только читает статистику; она не запускает, не останавливает и не меняет сервер.
TPS доступен, когда панель получает данные игрового StatsMod. Отсутствующие показатели обозначаются прочерком.
