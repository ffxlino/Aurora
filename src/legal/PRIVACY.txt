# Конфиденциальность

Редакция для проверки: 15 октября 2026. Относится к текущей реализации Aurora. Публичное имя автора — Fish Fox Lino (профиль ffxlino); данные оператора облачного сообщества пока не уточнены; до широкого выпуска необходимо подтвердить правовые данные оператора и контакт для запросов о данных. Приватные сообщения об уязвимостях GitHub уже включены.

## Локальные данные

Aurora сохраняет на компьютере установки Minecraft, список сборок, настройки, кеш, резервные копии и журналы. По умолчанию используется пользовательский профиль приложения, а не папка скачанного EXE. Microsoft-токены и сохранённые пароли подключений шифруются через системное защищённое хранилище. Это не означает шифрование миров, модов и произвольных конфигов. На Linux необходим доступный сервис секретов.

## Сетевые обращения

Вход использует Microsoft, Xbox и Minecraft. Каталог и скачивание используют Modrinth, CurseForge и соответствующие CDN. CurseForge API-ключ проекта остаётся на сервере прокси. Общая библиотека использует Cloudflare и GitHub. Проверка обновлений обращается к GitHub Releases. Сохранённые серверные подключения обращаются к указанному игровому серверу, панели мониторинга и файловому серверу.

Провайдеры получают технические сведения запроса, включая IP и время, в соответствии с собственными правилами. Aurora не управляет их независимыми сроками хранения. Windows и Linux могут использовать собственные сетевые и системные службы.

Если пользователь выбирает подтверждение Minecraft-аккаунта для доступа к сообществу, краткоживущий игровой токен Minecraft передаётся выбранному серверу сообщества для проверки профиля через Minecraft API. Это не передача пароля Microsoft или refresh-токена. Пользуйся только доверенным сервером сообщества.

## Публичные и социальные данные

Публикация общей сборки делает доступными её название, имя редактора приглашения, даты, изменения, mods и config. Вложения могут быть скопированы посторонними. Миры и файлы аккаунтов не входят в общую публикацию. Проверяй конфиги на пароли, личные адреса и ключи даже после автоматической проверки.

Присутствие в сообществе передаётся при включённой настройке; социальные функции хранят необходимые заявки и отношения друзей. Discord Rich Presence настраивается отдельно и передаёт активность локальному Discord-клиенту. Имя редактора приглашения не является подтверждённой личностью Microsoft.

## Отчёты и аналитика

В текущем коде нет рекламной аналитики и автоматической отправки crash-report. Пользователь сам экспортирует и отправляет отчёт. Очистка скрывает известные типы секретов, но не гарантирует удаления всех персональных данных из журналов сторонних модов: перед отправкой нужен просмотр.

Сайт Aurora не содержит сторонней аналитики, рекламных SDK и форм сбора паролей. Запрос к GitHub для проверки доступных выпусков получает технические данные соединения. Хостинг сайта может вести собственные журналы; режим определяется провайдером размещения.

## Хранение и удаление

Локальные сборки, настройки и копии остаются до удаления пользователем. Выход из аккаунта не удаляет игровые миры, общие публикации, облачные журналы и данные провайдеров. Удаление локального профиля может лишить доступа к сохранённым данным: сначала сохрани нужные миры и копии.

В разделе «Друзья» можно удалить свой социальный профиль: текущий код друга, связи, заявки и статус удаляются из активного хранилища; профиль не создаётся автоматически заново. При желании пользователь создаёт новый профиль с новым кодом. Приглашение, права редактора, авторство публикаций и файлы общей библиотеки сохраняются. Это не удаление всех облачных данных.

У облачного сообщества пока нет общего пользовательского механизма удаления всех данных и единого гарантированного срока хранения. Для прав, социальных записей и публикаций обращайся к владельцу сообщества. Удаление публичного файла не отзывает чужие копии, кеши и резервные копии. Формальные сроки, порядок запросов и контакт оператора — обязательные пункты до выпуска 1.0.
