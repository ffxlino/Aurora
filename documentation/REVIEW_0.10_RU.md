# Aurora 0.10 — проверочная сборка

Лаунчер не опубликован в GitHub. Серверный API друзей обновлён совместимо с существующими сборками.

## Мониторинг Bisect

Открой «Серверы», на карточке своего сервера нажми «Мониторинг». Вставь полный ключ API панели в защищённое поле и сохрани. Не отправляй ключ в чат и не добавляй его в исходники. Он шифруется локальным системным хранилищем; если безопасное хранилище недоступно, сохранение блокируется. Ключ не включён в EXE.

Если сервер не найдётся автоматически, укажи идентификатор из адреса страницы сервера в игровой панели. Числовой идентификатор заказа 32502632 может отличаться от идентификатора API. CPU и память берутся из панели; TPS показывается только если панель возвращает это значение. Новый ключ пользователя ещё не проверен реальным запросом.

Выбери основной сервер на его карточке: онлайн и количество игроков появятся в боковой панели. Без ключа доступны игровой статус, игроки и задержка.

## Что проверить

- Сохранение ключа, повторное открытие мониторинга и показатели реального сервера.
- SFTP: чтение и сравнение модов. Тайм-аут теперь зависит от отсутствия данных, а не всей длительности передачи; ошибка указывает файл. Короткое чтение реального сервера проверено, полное сканирование большой сборки требует проверки.
- Фильтры каталога: сортировка, категории, совместимость версии и загрузчика.
- Друзья: каждый использует своё персональное приглашение сообщества. Заявка требует взаимного принятия; статус можно скрыть. Для публичной сборки показывается название, для локальной — общий статус Minecraft. Идентичность приглашения пока не является глобальным подтверждённым аккаунтом Microsoft.
- Русский и английский основной интерфейс. Некоторые сообщения диагностики и отдельное окно консоли ещё могут оставаться русскими.

Discord Presence подготовлен, но выключен по умолчанию. Для реальной проверки нужен отдельный публичный Application ID Aurora и работающий Discord. Токен бота не нужен.

## Проверки

86 тестов лаунчера и 8 тестов сервера прошли. Один Linux-тест пропущен на Windows. Проверка исполняемого файла выполняется отдельно на чистом тестовом профиле. Arch-сборка и реальный запуск под Linux остаются отмеченными задачами: доступной среды Arch сейчас нет.

Будущее: общий безопасный прокси мониторинга без передачи ключа игрокам; очистка прежних архивных GitHub Releases после проверки ссылок; собственный хостинг и сайт. Пользовательские миры и файлы сервера не менялись при проверках.

Переносимый EXE 0.10.0 проверен на отдельном чистом профиле: завершение с кодом 0; встроенные проверки интерфейса прошли. Упакованные 55 исходных файлов совпадают с проверенными исходниками.
