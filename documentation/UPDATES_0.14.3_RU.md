# Aurora 0.14.3: зависимости и автоматическая проверка обновлений

## Выбор зависимостей

Для зависимости без точной версии выбирается самый свежий совместимый стабильный файл по дате публикации. Проверяются все страницы версий, а не первый релиз из первой страницы. В отсутствие стабильного файла допускается совместимая предварительная зависимость с предупреждением в подтверждении установки.

Если автор мода закрепил version_id, используется указанная версия. В плане установки показываются название и версия этой зависимости и сообщение, каким модом она задана. У Hex Casting 0.11.4 API действительно содержит такие ограничения; принудительная замена на более новую версию может нарушить работу.

## Уведомления

- При открытии сборки запускается фоновая проверка известных Modrinth/CurseForge ресурсов. Повторная автоматическая проверка — через пять минут, пока сборка открыта на вкладке библиотеки и лаунчер не занят операцией.
- Обновление отображается кнопкой у файла; подсказка показывает текущую и предлагаемую версии. Рядом со списком есть «Обновить всё» и «Проверить снова».
- Обе кнопки ведут к предварительному просмотру с версиями до/после и обязательными зависимостями, затем к подтверждению и резервной копии сборки с мирами.
- Стабильные установки остаются на release; Beta допускает release/beta; Alpha — release/beta/alpha. Версии с более старой датой публикации не предлагаются как обновление.
- Modrinth проверяется пакетно по SHA-1. Известные версии сверяются с файлами источника; несовпадение даёт ошибку проверки, а не произвольное обновление.
- Известная точная зависимость неизменяемого родительского мода не предлагается к отдельному обновлению. При обновлении связанных модов план проверяет согласованность выбранных версий. Это проверка доступных метаданных, не гарантия отсутствия любых конфликтов модов во время игры.
- Неопознанные локальные файлы и отключённые моды не обновляются автоматически. Для локальных файлов сначала используй «Распознать источники».

Проверки версий кешируются: интерфейс — до пяти минут для неизменившегося списка, серверная часть локального приложения — до минуты. Уведомления не означают автоматическую замену файлов. API-ошибки отображаются отдельно от отсутствия обновлений.

## Проверки

128 тестов прошли, один платформенный Linux-тест пропущен. Покрыты пагинация, закреплённые версии, каналы предварительных выпусков, запрет понижения, проверка хешей и сохранение копии перед обновлением. Интерфейс проверен на отдельном профиле, включая кнопки отдельного обновления и обновления всех ресурсов.

Общая библиотека и игровой сервер не изменялись. Новая версия подготовлена локально для проверки; публикация не выполнялась.
