# Aurora — Minecraft Launcher

Самостоятельный настольный лаунчер для **Windows 10/11 x64** и **Minecraft Java Edition 1.18+**. Интерфейс на русском языке. Это независимое приложение, не официальный продукт Mojang или Microsoft.

## Запуск готового приложения

Откройте `dist/Aurora-0.2.0-Windows-x64.exe`. Установка Node.js, Java или .NET пользователям не нужна. Лаунчер сам скачивает подходящую Java. При первом запуске игры требуется интернет и свободное место под Minecraft, моды и ресурсы. EXE переносимый; пользовательские данные сохраняются в `%APPDATA%/aurora-launcher`, а не внутри EXE.

1. В настройках укажите Microsoft Application (Client) ID, если владелец ещё не встроил его в дистрибутив.
2. Нажмите «Войти в Microsoft». Введите показанный код на открывшейся официальной странице Microsoft. Нужен аккаунт с Minecraft Java Edition.
3. Создайте сборку, импортируйте `.mrpack` / ZIP CurseForge или установите сборку из каталога Modrinth / CurseForge.
4. Выберите сборку и нажмите «Играть». Кнопка «Проверить / установить» позволяет заранее загрузить игру без входа.

Старые отдельные Mojang-аккаунты не используются: авторизация реализована через Microsoft → Xbox Live → Minecraft Services. Пароль Microsoft лаунчер не запрашивает. Refresh token зашифрован средствами Windows через Electron safeStorage.

## Настройка входа Microsoft — один раз для владельца

**Без собственного Client ID рабочий вход проверить и использовать нельзя.** В проект не включены чужие ключи или секреты. Client ID — публичный идентификатор, это не Client Secret.

1. В Microsoft Entra создайте регистрацию приложения с поддержкой личных Microsoft accounts (Personal Microsoft accounts; либо accounts in any organization + personal accounts).
2. В разделе Authentication включите **Allow public client flows** для Device Code Flow. Используется endpoint `consumers` и scope `XboxLive.signin offline_access`; Client Secret не нужен.
3. Проверьте, разрешён ли вашему приложению доступ к Minecraft Services. Для новых сторонних лаунчеров Microsoft/Mojang может требовать отдельного одобрения. Успешного Xbox-входа недостаточно, если Minecraft API не допускает приложение.
4. Скопируйте Application (Client) ID в настройки Aurora.
5. Для распространения среди друзей впишите его в `launcher.config.json` → `microsoftClientId` и повторно соберите EXE. Тогда друзьям не нужно вводить ID.

Официальные справочные страницы:
- https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-device-code
- https://learn.microsoft.com/en-us/entra/identity-platform/quickstart-register-app

Настоящий вход и вход в игровой мир нужно проверить с вашим разрешённым Client ID и лицензированным аккаунтом. Автоматические тесты не подменяют эту проверку.

## Сборки и моды

- Vanilla, Fabric, Quilt, Forge, NeoForge. Для Forge и NeoForge укажите точную версию загрузчика, совместимую с выбранным Minecraft. Например, Forge `52.1.0` или NeoForge `21.1.259` для Minecraft `1.21.1`.
- Fabric / Quilt могут выбрать доступную стабильную версию автоматически. После установки точная версия сохраняется.
- Единый каталог Modrinth + CurseForge: сборки, моды, ресурспаки и шейдеры; общий поиск либо выбор одного источника, страницы результатов и совместимых версий. Для CurseForge нужен собственный API key в настройках. Если один сервис недоступен, результаты второго остаются доступны.
- Для модов фильтруются Minecraft и загрузчик, скачиваются обязательные зависимости. Перед установкой встроенное окно показывает список файлов и целевую сборку. Шейдеры устанавливаются в shaderpacks, ресурспаки — в resourcepacks. Включите их в игре; шейдерам нужен Iris или OptiFine. Полную совместимость произвольного сочетания модов окончательно проверяет загрузчик игры.
- Карточки установленных ресурсов показывают иконку, описание, версию, источник и переключатель модов. Категории: «Клиент», «Сервер», «Оба» и «Не определено». Последняя используется, если источник и файл не сообщают сторону. Категорию можно уточнить вручную или вернуть «Авто».
- «Распознать файлы» ищет точные совпадения по контрольным суммам в каталогах. Такие источники помечаются «найден», поскольку совпадение не доказывает место исходного скачивания. Вручную изменённый файл распознаётся заново. Источник скачанных и импортированных ресурсов сохраняется отдельно от игровых файлов.
- Подтверждения архивирования, публикации, замены конфликтующих файлов, установки и закрытия работающего лаунчера встроены в интерфейс Aurora. Системный выбор файлов и защитные запросы самой Windows остаются системными.
- Импорт `.mrpack` устанавливает файлы клиента и применяет `overrides` / `client-overrides`.
- Импорт CurseForge ZIP требует собственного API key в настройках. Запрет автора на стороннюю загрузку не обходится; вместо этого выводится ошибка с названием файла.
- Общие и импортируемые файлы ограничены каталогами `mods`, `config`, `resourcepacks`, `shaderpacks`, `defaultconfigs`, `kubejs`. Вложения в другие корневые папки из модпаков не переносятся. Миры и исполняемые скрипты Windows не импортируются.
- Добавление локальных файлов, отключение/включение `.jar`, журнал, резервные копии заменяемых файлов, переименование и архивирование сборок.
- Экспорт `.mrpack` включает локальные файлы в overrides. Делитесь только теми модами и ресурсами, распространение которых разрешено авторами.
- При установке рекомендуется оставить Aurora открытой. «Архив» перемещает всю сборку, включая миры, в папку `trash` рядом с данными приложения. Автоматическая очистка архива не выполняется.

## Общая сборка для друзей

### Владелец

1. Откройте «Вместе с друзьями» → «Создать своё пространство».
2. Придумайте мастер-пароль минимум из 12 символов. При повторном запуске сервера нужен этот же пароль.
3. Добавьте Minecraft UUID редакторов в белый список, по одному на строке. Свой UUID игрок видит после входа в настройках. Список сохраняется; изменить его можно при следующем запуске сервера.
4. Запустите сервер. Он использует HTTPS и собственный сертификат. Отправьте друзьям адрес и SHA-256 отпечаток сертификата. Отпечаток передавайте по доверенному каналу.
5. Подключитесь сами через форму слева с адресом, отпечатком и мастер-паролем. Выберите локальную сборку в библиотеке и нажмите «Опубликовать выбранную».

### Игроки

1. Войдите в Microsoft, укажите адрес и отпечаток. Мастер-пароль не нужен обычному игроку.
2. Нажмите «Скачать / обновить». Первое скачивание создаёт отдельную локальную сборку.
3. Запускайте эту сборку из библиотеки. Для изменений добавьте/замените файлы локально и опубликуйте новую ревизию, если у вас есть права редактора.
4. После изменений друзей нажмите «Скачать / обновить». Если есть локальные конфликты, приложение запросит подтверждение; перезаписываемые файлы сохранятся в `backups`.

**Роли:** читатель может скачивать; редактор из белого списка может публиковать; мастер-пароль даёт права администратора. Владение UUID подтверждается сервером через Minecraft Services, а не доверяется введённому имени. Мастер-пароль хранится как scrypt-хэш с солью. Авторизация действует один час, затем требуется повторное подключение.

**Журнал:** автор, UUID, время в UTC (в интерфейсе — местное время), номер ревизии, список добавленных/изменённых/удалённых файлов. Последние 1000 публикаций сохраняются сервером. У подключённых клиентов журнал обновляется каждые 15 секунд. Загрузка файлов выполняется вручную. Публикации используют проверку ревизии, чтобы один редактор не перезаписывал незамеченные изменения другого.

**Сеть:** сервер слушает выбранный TCP-порт, по умолчанию 25580. В локальной сети Windows может запросить разрешение брандмауэра. Через интернет нужен доступный внешний адрес и перенаправленный порт или общая VPN-сеть; EXE сам не настраивает роутер. Для друзей дополнительных компонентов приложения не нужно, но связь с сервером должна быть доступна. Сервер работает, пока открыт лаунчер владельца. Это **сервер файлов**, не игровой сервер Minecraft; для совместной игры нужен отдельный Minecraft-сервер или LAN-мир.

**Ограничения этой версии:** один общий модпак на сервер; файл до 100 МБ, общий манифест до 2 ГБ, до 10 000 файлов, до 100 активных сессий. Нет автозапуска сервера при включении Windows, облачного хостинга, автоматического обновления самого лаунчера и цифровой подписи EXE. Сервер рассчитан на небольшую доверенную группу друзей, не на публичный сервис. Моды исполняют Java-код: права редактора следует давать только доверенным участникам.

## Сборка из исходников

Требуется Node.js 22+ и npm на машине разработчика:

```powershell
npm ci
npm test
npm start
npm run dist
```

Готовый файл: `dist/Aurora-0.2.0-Windows-x64.exe`. Java и игровые файлы скачиваются при первом использовании и не включены в EXE. Сборка упаковывает собственный runtime Electron. Каталоги `artifacts`, `test` и тестовые аккаунты не входят в дистрибутив.

## Проверки

Автотесты: безопасные пути Windows; правила JVM; распаковка; импорт `.mrpack`; включение/отключение модов; резервное копирование; HTTPS с закреплённым сертификатом; неверный пароль; белый список; запрет записи читателю; контроль SHA-256; конфликт одновременных публикаций; синхронизация и защита локальных изменений.

Проверена настоящая загрузка Minecraft 1.21.1 и Java 21, а также установка Fabric, Forge и NeoForge. Полноценный запуск игры с лицензией не проверен без пользовательского Microsoft Client ID. Сам факт успешной установки не гарантирует работоспособность каждой комбинации модов.

## Структура

- `src/main.js` — главное окно, разрешённые действия, настройки.
- `src/preload.js` — ограниченный мост интерфейса к приложению.
- `src/core/auth.js` — Microsoft / Xbox / Minecraft OAuth.
- `src/core/minecraft.js` — Java, игра, загрузчики, запуск.
- `src/core/packs.js` — импорт, каталог, моды, копии и журнал.
- `src/core/hub.js` — HTTPS-сервер, роли, ревизии, синхронизация.
- `src/core/util.js` — безопасные пути, хеши и загрузки.
- `src/ui` — интерфейс и оригинальные графические ресурсы Aurora.

Исходники приложения распространяются по MIT; лицензии сторонних зависимостей и игровых компонентов сохраняются отдельно. Minecraft, Java и моды не поставляются как собственность Aurora.
