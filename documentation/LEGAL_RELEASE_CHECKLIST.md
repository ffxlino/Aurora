# Правовой выпуск Aurora

Подготовительная редакция от 15 октября 2026. Правила конкретной страны и владельца ещё нужно определить. Этот документ не регистрирует права и не заменяет проверку специалистом перед коммерческим или широким публичным распространением.

- [x] Публичное имя автора подтверждено пользователем: Fish Fox Lino, профиль ffxlino. Существующее уведомление Aurora contributors сохранено.
- [ ] Уточнить данные правообладателя и оператора облачного сервиса для применимого законодательства.
- [ ] Указать страну оператора, действующий приватный контакт и порядок запросов на удаление. Не использовать личную почту со скриншотов без согласия.
- [ ] Проверить название Aurora и похожие обозначения в нужных территориях и классах товаров/услуг. Не заявлять зарегистрированный товарный знак до регистрации.
- [ ] Сохранить MIT и уведомления об авторстве для уже распространяемого кода. Не пытаться отозвать права, уже предоставленные MIT, новой страницей сайта.
- [ ] Зафиксировать происхождение логотипа, иконок, обложек и любых заимствованных материалов. Политика бренда не отменяет действующие лицензии на уже открытые графические файлы.
- [ ] Проверить лицензии каждого вложенного JAR и конфигурации перед публичной публикацией. Разрешение API CurseForge не даёт автоматического права перезаливать файлы.
- [ ] Проверить THIRD_PARTY_NOTICES и SBOM; сохранить LICENSE Electron и LICENSES.chromium.html вместе с бинарной средой.
- [ ] Указать независимость от Mojang/Microsoft и права их владельцев; не выдавать API allow-list за одобрение продукта.
- [ ] Утвердить политику конфиденциальности: фактические данные, цели, провайдеры, сроки, удаление, публичность сборок. Не обещать автоматическое удаление, пока его нет.
- [x] Включён GitHub Private Vulnerability Reporting; состояние подтверждено API владельца 15 октября 2026.
- [ ] Проверить отправку приватного обращения с другого аккаунта (без искусственных уязвимостей в публичных Issues).
- [ ] Решить условия будущих платежей отдельно: сейчас платёжная система, подписка и условия платных услуг не вводятся.

Официальные источники, проверенные при подготовке:

- https://www.minecraft.net/en-us/usage-guidelines
- https://www.wipo.int/en/web/copyright/protection
- https://choosealicense.com/licenses/mit/
- https://support.modrinth.com/en/articles/8797527-obtaining-modpack-permissions
- https://docs.curseforge.com/rest-api/
- https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately

Авторское право на охраняемое оригинальное выражение во многих странах возникает автоматически; оно не делает идею лаунчера или общее слово Aurora исключительно принадлежащими проекту. Объём прав зависит от применимого законодательства и происхождения каждого материала.
