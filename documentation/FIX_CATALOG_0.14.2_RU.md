# Aurora 0.14.2: установка модов без стабильного релиза

## Причина

Автоматическая установка намеренно выбирала только release. Для Hex Casting под Minecraft 1.20.1 / Forge API Modrinth возвращает только beta. Вместо выбора версии из каталога интерфейс показывал сообщение, предлагавшее открыть список уже установленных модов; в чистой сборке это было невозможно.

## Исправление

Если есть совместимый стабильный релиз, автоматический выбор работает как прежде. Если есть только предварительные версии, каталог сразу открывает окно выбора с предупреждением и пометками Beta/Alpha. Установка происходит после выбора версии и подтверждения списка зависимостей. Предупреждение относится и к предварительным обязательным зависимостям.

Если совместимых файлов нет совсем, отображается отдельное сообщение о версии Minecraft/загрузчике и пустой список; несовместимый файл не устанавливается. Сохраняются выбранная сборка, источник и мир для датапака.

## Проверки

- Тесты Beta-only для Modrinth и CurseForge: до выбора и подтверждения файлы не скачиваются, после явного выбора устанавливаются с контрольной суммой.
- Стабильный релиз остаётся приоритетным, даже если beta новее.
- Несовместимые версии не устанавливаются.
- Проверка интерфейса на чистом профиле: открытие окна выбора Beta из каталога, без предварительно установленного мода.
- Реальный запрос к официальному Modrinth: Hex Casting forge-1.20.1-0.11.4 и пять обязательных зависимостей успешно включены в план. Игра с этим набором не запускалась; пользовательские сборки не изменялись.
- Полный набор: 123 теста прошли, один Linux-тест пропущен.

Изменения 0.14.1 по проверке и восстановлению файлов общей сборки сохранены. Новая публичная версия и сервер не публиковались.
