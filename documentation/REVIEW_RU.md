# Проверка удобства и функциональности Aurora 0.3.0

Добавлено: работа только с Modrinth; официальный режим запуска без недоступного прямого входа; изолированные профили для сборок; автоматический выбор Java и библиотек Windows/Linux; AppImage и пакет pacman; выбор и сохранение пути к лаунчеру; открытие latest.log; сортировка сборок; реальные номера версии в интерфейсе; повтор загрузок при сетевом сбое.

Следующие приоритеты:

1. Управление зависимостями при удалении ресурса и безопасное обновление всех модов с предварительным просмотром и откатом. Сейчас установлены необходимые зависимости, но массовое обновление не реализовано.
2. Восстановление резервных копий и архивированных сборок из интерфейса. Сейчас файлы сохранены и доступны через Проводник/файловый менеджер.
3. Постоянный сервер общих сборок и управление участниками. Пока работает только встроенный сервер при открытой Aurora; у пользователя ещё не выбран внешний хостинг.
4. Прямой вход и запуск после одобрения Mojang; включение CurseForge после одобрения API. Не заимствовать учётные данные других лаунчеров.
5. Проверка Linux на реальной системе Arch/Wayland. CI проверяет Linux под Ubuntu и совместимые пакеты, но не может подтвердить все драйверы и окружения пользователя.
6. Отслеживание процесса игры и загрузка crash reports в интерфейсе. Сейчас официальный лаунчер запускает игру независимо; Aurora открывает её настоящий журнал, но не может надёжно определить завершение или заблокировать изменения файлов во время игры.

Ограничение временного режима: вход сохраняется в официальном лаунчере и не отображается как подтверждённый аккаунт Aurora. Полный запуск с лицензией требует проверки пользователем. Первичная загрузка игры и установка официального лаунчера требуют доступа к интернету.
