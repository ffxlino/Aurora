# Что потребуется от Fish Fox Lino

Обновлено 15 октября 2026. Разработка, тесты, подготовка сайта и документов — работа разработчика. Ниже только решения, личные данные и действия, которые нельзя достоверно выполнить вместо владельца.

## Сейчас: резервная копия ключа выпуска

Ключ Ed25519 уже создан в защищённом хранилище Windows текущего пользователя. В проекте находится только открытый ключ. Потеря компьютера без копии закрытого ключа нарушит непрерывность доверия обновлений.

1. Открой терминал в папке проекта.
2. Подключи свой защищённый внешний носитель. Выбери новый файл вне проекта, Git и публичной синхронизации.
3. Выполни `npm run release:key -- backup "E:\Aurora-release-key.encrypted.pem"`, заменив путь своим. Если зависимости облачных инструментов отсутствуют, сначала `npm ci --prefix cloud`.
4. Придумай пароль минимум из 20 символов. Введи дважды в терминале: ввод скрыт. Не присылай пароль или файл в чат; храни пароль отдельно.
5. Сохрани вторую защищённую копию и проверь восстановление на отдельной доверенной машине по RELEASING_RU.md. Не переустанавливай Windows до резервирования.

Зашифрованный файл — не обычный публичный сертификат: его тоже нельзя публиковать. Буква E приведена только как пример, подключённый носитель не обнаруживался.

## Перед широким выпуском: сведения об операторе

Нужно сообщить страну, в которой ты выступаешь владельцем/оператором сервиса, и определить необходимые публичные реквизиты по применимому законодательству. Имя Fish Fox Lino уже согласовано как публичное имя автора, но оно не заменяет обязательные юридические сведения.

Для запросов о персональных данных выбери отдельный доступный контакт. Можно создать отдельный бесплатный почтовый ящик проекта; домен и «корпоративная» платная почта не обязательны. Личную почту из скриншотов мы не публикуем. Приватные сообщения об уязвимостях GitHub уже включены и не требуют новой почты.

После выбора страны и контакта разработчик обновит документы. Решения об официальной регистрации, оплате и заключении договоров принимает владелец.

## Название Aurora

Название сохраняется. Прочитай BRAND_RESEARCH_RU.md: предварительный поиск обнаружил совпадения в той же области, но не установил запрет использования или свободу регистрации. Определи страны распространения и проверь обозначение в соответствующих реестрах; при необходимости обратись к специалисту по товарным знакам. Не ставь ® до регистрации. Разработчик подготовит варианты нового имени, если решение о смене понадобится.

## Проверка выпуска

- Открой локальную review-сборку 0.14, проверь свои сборки, вход, сервер и привычные действия. Сначала сохрани миры и настройки.
- После проверки сообщи замечания или подтверди готовность к публикации; локальный файл и сайт ещё не выложены как новый публичный выпуск.
- Для Arch нужна реальная машина или предоставленная тестовая среда. Разработчик выполнит доступные проверки; если машину предоставить нельзя, тестировщик должен пройти X11/Wayland, secret service, трей, запуск игры, SFTP, обновление и восстановление. Windows-проверки этого не заменяют.
- Если нужна Windows Authenticode-подпись и меньше предупреждений при распространении, владелец проходит проверку личности у выбранного поставщика и принимает условия/расходы. Ed25519 уже защищает канал обновлений, но не заменяет такую подпись.

## Что остаётся задачами разработки

Полное удаление облачных данных с политикой хранения, испытание восстановления сервера, аудит лицензий вложенных модов, устойчивость прерываемых операций и оставшаяся матрица до 1.0 находятся в PROJECT_AUDIT_RU.md. Они ещё не объявлены выполненными.
