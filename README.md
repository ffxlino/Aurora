# Aurora 0.10.0

Настольный лаунчер Minecraft Java 1.18 и новее для Windows и Linux x64.

## Вход и запуск

Mojang одобрил приложение Aurora. Прямой вход Microsoft проверен с лицензированным аккаунтом, запуск Minecraft 1.20.1 / Fabric проверен на Windows. В настройках также можно выбрать запуск через официальный Minecraft Launcher.

1. Открой Aurora и нажми «Войти в Microsoft».
2. Открой указанный сайт Microsoft, введи код из Aurora и подтверди вход.
3. Создай сборку, импортируй .mrpack или установи сборку из Modrinth / общей библиотеки.
4. Нажми «Играть»: Aurora проверит общую версию, установит подходящую Java, Minecraft и загрузчик и запустит игру.

Client ID уже настроен. Вход сохраняется зашифрованным через системное хранилище. На Linux нужно доступное хранилище секретов рабочего стола; при отсутствии защищённого хранилища Aurora откажется сохранять токены. Для игры нужен аккаунт с Minecraft Java Edition. Каталог пока использует только Modrinth; CurseForge ожидает одобренный ключ приложения.

## Общие сборки

Общие сборки находятся в «Мои сборки». Игрокам доступны установка и история без аккаунта GitHub. На карточке общей сборки есть «Изменить сборку»; редакторы вносят изменения в локальную копию и нажимают «Опубликовать изменения». Перед публикацией виден список затронутых файлов.

Актуальная сборка публикуется одним архивом в публичном репозитории https://github.com/ffxlino/Aurora-Packs . Известные файлы Modrinth скачиваются из Modrinth; собственные файлы и .mrpack размещаются в GitHub Releases. Конфиги собираются в overrides архива .mrpack. Миры и файлы аккаунтов не публикуются. Конфиги с распознанными паролями или ключами блокируются; проверь собственные файлы перед публикацией.

Живой журнал обновляется каждые 15 секунд при открытом приложении. Он показывает автора, дату и добавленные, изменённые и удалённые файлы. Для изменённого файла доступны прежний хеш и ссылка на прежний файл или .mrpack.

Перед запуском общая сборка автоматически проверяется. При обновлении создаётся резервная копия; если игрок изменил затронутые файлы, Aurora запрашивает подтверждение. Локальные миры сохраняются. После обновления игра запускается выбранным способом. Одновременная публикация двумя редакторами блокируется; совместное редактирование текста в реальном времени не предусмотрено.

## Участники

В библиотеке открой «Доступ редактора». Владелец входит с мастер-паролем; приглашения и права сохраняются на сервере независимо от запущенной Aurora. На настроенном компьютере владельца пароль уже сохранён в защищённом хранилище. Через «Участники и права доступа» можно создать приглашения читателя / редактора или разрешить редактирование по UUID Minecraft. Кнопка «Использовать аккаунт Minecraft» проверяет UUID через Minecraft API. На текущем облаке API отвечает HTTP 403; используй приглашения редакторов до восстановления этой проверки. Прямой вход и запуск игры в Aurora работают. Имена приглашений задаёт владелец, это не проверенная личность Microsoft. Отзыв доступа отключает текущие сессии.

GitHub-ключ хранится только в секрете сервера Cloudflare. Пользователи лаунчера его не получают. Для публикации ключу нужны Aurora-Packs и разрешение Contents: Read and write. HTTP 404 от GitHub при создании релиза означает, что нужно проверить выбранный репозиторий и доступы ключа.

## Возможности

Каталог Modrinth: сборки, моды, ресурспаки и шейдеры; поиск совместимых версий и обязательные зависимости. Карточки ресурсов с источником, описанием и категориями «Клиент», «Сервер», «Оба»; выключение модов. Импорт / экспорт .mrpack и добавление локальных файлов. Резервные копии, откат обновлений, диагностика и очищенные отчёты. Память, Java и размер окна отдельно для каждой сборки. Избранное, теги, обложки, очередь загрузок с паузой, совместимые загрузчики, архивирование с сохранением миров. Подтверждения внутри интерфейса.

## Linux / Arch

Aurora-0.6.0-Linux-x86_64.AppImage: разреши выполнение в свойствах и открой файл. Без FUSE 2 используй --appimage-extract-and-run либо пакет pacman.

Aurora-0.6.0-Linux-x64.pacman: `sudo pacman -U ./Aurora-0.6.0-Linux-x64.pacman`. Пакет объявляет зависимости графики, звука и GTK. Поддерживается x86_64. Сборка, интерфейс и установка Java / Fabric проверяются в Ubuntu CI; Arch / Wayland требуют проверки на устройстве.

Для прямого запуска официальный лаунчер не требуется. Для выбранного режима Minecraft Launcher установи его отдельно с https://www.minecraft.net/download и при необходимости укажи путь в настройках. В нём нужно выбрать профиль «Aurora · название сборки» и нажать «Играть». Aurora не отслеживает игру, запущенную внешним лаунчером.

## Постоянный сервер и лимиты

Метаданные, права и временная загрузка файлов работают на Cloudflare Workers Free / SQLite Durable Objects, без R2 и платного тарифа. Файлы готовых версий хранятся в GitHub Releases; сервер продолжает работать при закрытом приложении. Для совместной игры нужен отдельный Minecraft-сервер или LAN-мир.

Ограничения Aurora: 4 000 000 000 байт на сборку, 512 МиБ на отдельный файл, до 998 собственных файлов вне .mrpack на одну версию. Проверенная большая сборка не является нагрузочным тестом публикации 4 ГБ. Квоты бесплатных провайдеров могут временно остановить операции. Бесплатные 5 ГБ Cloudflare распространяются на весь аккаунт, включая другие проекты; файлы, переданные GitHub, удаляются из временного хранилища. Не подключай платный тариф или R2, если требуются отсутствие карты и списаний.

## Разработка

`npm ci`, `npm test`, `npm start`. Windows: `npm run dist`. Linux: `npm run dist:linux` на Linux. Сервер: `npm ci --prefix cloud`, `npm test --prefix cloud`. Проверка установки Java / Fabric: `npm run verify:engine`.

При обновлении закрой старую Aurora и открой новый файл. Сборки и настройки сохраняются в прежнем профиле пользователя.

## Новое в 0.6

Статус-бар показывает текущий этап, объём, скорость и приблизительное время передачи. Передача файла, проверка, сохранение в GitHub и окончательная публикация показаны отдельно. Успешная операция заканчивается явным статусом; конфиги тоже учитываются, поэтому прежний зависший процент исправлен. В ожидании сервера время передачи не выдаётся за точный срок завершения.

Обновления самого лаунчера проверяются при запуске и каждые 30 минут. Если найден новый опубликованный выпуск Aurora с подходящим файлом и SHA256SUMS, появляется кнопка обновления. Сначала файл скачивается и проверяется, затем отдельная кнопка предлагает перезапуск. Windows portable и Linux AppImage заменяются автоматически с восстановлением прежнего файла при неудачной замене. Для установленного Arch pacman скачивается проверенный пакет и показывается команда установки: системная установка требует прав администратора. Версию 0.6 нужно скачать вручную один раз; предыдущие версии не содержат этого механизма.

Исправлен запуск Forge с дублированием исходного Minecraft JAR при несовпадении имени профиля. Ошибка проверена на копии Changed Horror / Forge 1.20.1; пользовательские миры не копировались. Метаданные Packwiz в mods/.index/*.pw.toml остаются служебными файлами и не заменяют JAR модов. В диагностику включены stderr_stream.log и stdout_stream.log.

## Aurora 0.10

Компактная библиотека и меню аккаунтов; дубликаты модов проверяются перед запуском, для сервера можно экспортировать ZIP без исключительно клиентских модов. Создание папок по имени сборки, контекстное меню карточек и локальные резервные копии.

Серверы представлены карточками. Основной сервер показывает онлайн и число игроков в боковой панели. Для расширенного мониторинга Bisect открой «Серверы → Мониторинг»: ключ API шифруется локально и не включается в приложение. TPS доступен только если его возвращает панель. SFTP использует тайм-аут простоя и параллельное чтение; доступ к удалённым файлам остаётся только для чтения.

Каталог поддерживает сортировку, категории, список/сетку, страницы и бесконечную прокрутку. Друзья добавляются по коду с взаимным подтверждением; публикация статуса выключена по умолчанию. Для контактов нужен собственный доступ по приглашению сообщества. Основной интерфейс доступен на русском и английском; часть диагностики ещё на русском. Discord Presence можно настроить отдельным Application ID; реальное подключение Aurora к Discord пока не проверено.

Общий архив содержит только mods и config. Для каждой отдельной сборки используется один активный архив; ревизии остаются в журнале. Старые архивные Releases автоматически не удаляются. Миры и личные настройки сохраняются локально.

Подробности текущей проверки: [VALIDATION.md](VALIDATION.md). Пользовательский API-ключ Bisect и реальные показатели с ним проверяются отдельно после локального ввода.
