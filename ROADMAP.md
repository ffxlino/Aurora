# CraftSync — Roadmap будущих обновлений

## v0.2.0 — Серверная инфраструктура

### Разделение модов client / server
- Парсинг `mods.toml` (поле `side = "CLIENT"` / `"BOTH"`) у каждого мода в архиве
- В манифесте сборки добавить поле `mods[].side: "client" | "both"`
- При установке клиенту — ставятся все моды (`client` + `both`)
- Серверная сборка — только `both`, без клиентских
- Предотвращает конфликты и ошибки при поднятии сервера

### Верификация сборки перед запуском
- Перед каждым запуском сравнивать хеши (MD5/SHA256) файлов в папке `mods/`
  с эталонными хешами из манифеста
- Если файл изменён или добавлен посторонний — предупреждение
- Кнопка «Восстановить сборку» для приведения к официальному состоянию

### Чистка сборки от неофициальных модов
- Кнопка «Очистить сборку» в меню сборки (шестерёнка)
- Удаляет файлы из `mods/`, которых нет в официальном манифесте
- Оставляет только моды из официального списка (равные условия для всех)
- Предварительный список что будет удалено с подтверждением

## v0.3.0 — Мультиплеер и социальные функции

### Основной сервер
- Карточка сервера на главной странице с онлайном, пингом, MOTD
- Кнопка «Подключиться» — запускает игру с IP сервера в аргументах
- Статус сервера (онлайн / офлайн / запускается)

### Авто-запуск сервера по требованию (Oracle / Exaroton API)
- Если сервер пустой — при нажатии «Подключиться» отправляет запрос на пробуждение
- Показывает прогресс запуска («Сервер запускается... 45 сек»)
- Авто-сон сервера когда никого нет в сети
- Интеграция с Exaroton API (или кастомный агент на Oracle)

### Вкладка активных игроков
- Список игроков онлайн на сервере (через RCON или внешний API)
- Возможность подключиться к тому же серверу что и друг
