# Участие в Aurora

1. Для ошибки используй шаблон Bug report; для идеи — Feature request. Уязвимости сообщай по SECURITY.md.
2. Укажи версию Aurora, ОС, Minecraft/loader и минимальные шаги. Не прикладывай полный профиль, токены и пароли. Просмотри очищенные отчёты перед публикацией.
3. Изменения должны сохранять миры и пользовательские файлы, изоляцию интерфейса, системное хранение секретов и правила распространения модов.
4. Для разработки: `npm ci`, `npm run content:build`, `npm test`, `npm start`. Облачные тесты: `npm ci --prefix cloud`, `npm test --prefix cloud`.
5. Новую функциональность проверяй подходящими тестами. Windows не заменяет Arch/Wayland; укажи фактически проверенные платформы. Не включай секреты в тестовые данные.
6. Код, на который у тебя есть необходимые права, отправляется под MIT проекта с сохранением атрибуции сторонних компонентов. Не добавляй чужой код или ресурсы без лицензии. Передача исключительных прав не требуется.

Готовый PR описывает проблему, изменение поведения, проверку и ограничения. Изменение политики данных, прав доступа или формата обновлений должно быть явно отмечено.
